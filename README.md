# Zenly 个人主页

基于原生 HTML/CSS/JS 制作，附带登录验证、加载入场动画、社交图标、多种粒子特效

预览站点：https://www.zenlydsp.top

##  特性
- 全屏动态背景，支持雪花、下雨、雷电粒子特效切换
- 访问优先跳转登录验证页面
- 页面资源加载完成渐进淡入入场动画
- 底部社交 SVG 图标栏，鼠标悬浮提示信息
- 数码管实时时钟 + Open‑Meteo 实时天气获取
- CSS 3D 旋转图片魔方展示模块
- JavaScript 事件循环可视化模拟器
- 时光胶囊时间进度统计面板
- 多套壁纸切换，设置自动本地存储记忆

##  部署方式
1. Fork 本仓库
2. Cloudflare Pages / Vercel 一键部署
